Q 盘环境手册：工具链、环境变量、新机器接入公用

唯一真值：工具链与环境变量 · 更新 2026-11-20 · 3,692 字

思路

工具链全装在 Q:\env\，不往 C 盘写。换机 = 插盘 + 固定盘符 Q: + 跑一次配置脚本 + 用激活过的终端。

必须用「激活过的终端」

Windows 的 PATH 顺序是系统 → 用户，机器上原有的 node / Oracle Java 8 会盖住盘上版本。把盘上 bin 插到当前会话最前面，不要改系统 PATH。

# 验收：四条命令都应指向 Q:\env\
flutter --version
node -v
java -version
